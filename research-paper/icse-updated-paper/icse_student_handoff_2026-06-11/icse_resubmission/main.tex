\begin{abstract}
AI coding agents increasingly propose GPU code changes, but evaluating those changes still depends on compile-run-profile loops on scarce target hardware.
This paper studies a narrower software-engineering question: can off-the-shelf large language models provide an execution-free early triage signal for GPU kernels before runtime profiling is available?

We formulate the task as predicting profiler-derived DRAM-level Roofline Arithmetic Intensity (\rai) from software artifacts.
For each first kernel invocation, the models predict launch dimensions, FP16/FP32/FP64 floating-point work, and DRAM bytes read and written; \rai follows from these quantities.
We evaluate 254 CUDA and OpenMP kernels (95 programs, 1{,}016 kernel-device rows) across four NVIDIA GPUs, comparing \sourceonly prompts against prompts that also include post-compilation SASS.

Across the completed evaluation subset, source-only reasoning is often sufficient for nonzero FP32/FP64 triage, but not for FP16.
Adding SASS produces the strongest gains for the frontier models, especially for FP16 and nonzero bandwidth-bound versus compute-bound decisions.
When rows are ranked by predicted \rai relative to the GPU balance point, the top 10\% of frontier-model \sourcesass predictions recover all shared-subset FP16 compute-bound rows, while source-only FP32 rankings already recover 82--96\%.
Simple deterministic and lightweight learned static baselines recover part of the same signal, underscoring the benchmark value beyond a single model family.
The strongest frontier LLMs remain best on \sourcesass FP16/FP32 triage, but lightweight learned baselines are competitive in some source-only FP16 and \sourcesass FP64 regimes while remaining poor numeric \rai regressors.
We also package the benchmark, prompts, responses, and plotting artifacts for follow-on work; public URLs are omitted in this anonymous version.
Our claim is therefore limited and practical: off-the-shelf LLMs can provide an execution-free triage signal for GPU kernels, but they do not replace profiling.
\end{abstract}
